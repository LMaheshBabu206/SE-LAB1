# Static analysis report files

Generate the before/after reports on the machine where Pylint, Bandit and Flake8 are installed by running the commands in ../commands.txt from the LAB5-47 folder.

The report files are intentionally not pre-filled: their contents must come from the actual tool versions and execution on the student's machine. Commit the generated *_before.txt and *_after.txt files here after running the commands.
